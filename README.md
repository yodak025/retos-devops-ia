# Retos DevOps e IA

Colección de retos prácticos sobre DevOps y desarrollo con inteligencia
artificial. Cada ejercicio parte de un enunciado y contiene una solución
ejecutable y documentada.

Algunos retos están inspirados en ejercicios realizados durante un bootcamp
especializado en DevOps; otros forman parte de mi aprendizaje y experimentación
personal.

## Retos

| Reto | Descripción |
| --- | --- |
| [Ansible](ansible/) | Despliegue de una aplicación Flask con Nginx mediante Ansible. |

## Organización

Cada reto se encuentra en un directorio independiente en la raíz del
repositorio. El archivo `ENUNCIADO.md` describe los requisitos y el `README.md`
de cada reto documentará la solución y su ejecución.
